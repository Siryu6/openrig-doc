OpenRig also runs on x86_64 PCs that boot in UEFI mode and have Intel graphics: an Intel N100
mini PC, a Lenovo ThinkCentre Tiny and the like.

:::danger[Check the CPU first: AVX2 is required]
Since 0.10.0 the image is built for **x86-64-v3**: the CPU needs **AVX2 and FMA**. Intel from
Haswell (2013) on, the N100 included, and AMD from Excavator and Zen on have them. Celerons and
Pentiums without AVX2 (J4125, N4020, N5105, J3455…) cannot start the image. From any Linux on that
PC (a live USB stick will do):

```bash
grep -o avx2 /proc/cpuinfo | head -1
```

It prints `avx2` if the CPU can run OpenRig, nothing otherwise. In exchange, the neural amp
models run about 1.8 times faster than with the older instruction set. More in
[What you need](../hardware/#x86_64-mini-pc).
:::

:::caution
The x86_64 image is tested in QEMU only so far. AMD graphics are not supported yet.
:::

<Steps>

1. Download `openrig-os-<version>-x86_64.img.xz` from the
   [releases page](https://github.com/Siryu6/OpenRig/releases).

2. Write it to a USB stick or an SSD, the same way as for the
   [Raspberry Pi](../raspberry-pi/). The whole disk is used: it erases it.

3. In the PC's firmware setup, **disable Secure Boot** and choose that disk to boot from.

4. Plug in the audio interface and the screen, and boot. Then go on with the
   [first start](../first-start/).

</Steps>

The settings file `pedalboard.txt` is on the first (EFI) partition of the disk. The kernel
arguments are in `EFI/BOOT/grub.cfg` there.

## Trying it without installing

The release also has the app alone for desktop Linux, `openrig-<version>-linux-x86_64.tar.gz`
(and `aarch64`). It needs JACK and lilv from the system:

```bash
sudo apt install jackd2 liblilv-0-0
jackd -d alsa -r 48000 -p 128 -n 2 &
./pedalboard
```

It opens in a window; nothing on the computer is changed.
