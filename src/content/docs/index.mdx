OpenRig is a guitar multi-effects pedalboard that you assemble from standard parts: a
Raspberry Pi 5 (or an x86_64 mini PC with an AVX2 CPU), a USB audio interface and a touchscreen. It ships as a
small operating system that boots straight into the pedalboard: no desktop, no login, no
computer needed once the card is written.

## What it does

- **Amps, pedals and cabinets** from [Neural Amp Modeler](https://www.neuralampmodeler.com)
  captures and impulse responses, as built-in blocks.
- **Multi-core DSP**: a heavy rig is spread over all four Cortex-A76 cores of the Pi 5, split
  branches and pipeline stages each on their core, with no added latency and the same sound.
- **LV2 effects**: LV2 plugins built for the board (ZAM, x42, Calf, LSP, CAPS…), and a store to
  install more from the screen.
- **TONE3000**: browse and download captures from [tone3000.com](https://www.tone3000.com)
  on the pedalboard itself.
- **Live**: presets with 8 scenes each, setlists, a stomp mode, tap tempo, a tuner and a
  looper, played from the screen, footswitches or MIDI.
- **Rigs**: a preset, its models and plugins packed in one file, shared and installed in one
  tap through [openrig.eu](https://openrig.eu/rigs).
- **An appliance**: a read-only system with a real-time kernel and signed updates that roll
  back if something goes wrong. Audio interface, buffer and screen rotation are set from the
  screen, and a plugin that crashes is caught while the dry signal plays on.

:::note[A young project]
OpenRig is at version <Version />. The Raspberry Pi 5 image runs on a Pi 5 (8 GB) with a Focusrite
Scarlett 2i2 at 128 × 2; the x86_64 image is tested in QEMU so far. If something does not work,
[open an issue](https://github.com/Siryu6/OpenRig/issues).
:::
