**⋮** → **Updates** opens the update dialog: the version of OpenRig (and of the system, on the
OpenRig OS), its license, and **Check for updates**, which compares your version with the
[latest release](https://github.com/Siryu6/OpenRig/releases). If there is a newer one, tap
**Install**: the dialog says how large it is and whether it is an app or a system update. The
pedalboard needs a network for this; nothing is checked or downloaded until you tap the button.

<Shot src={updates} alt="The update dialog: the OpenRig logo, the version of the app and the system, the license, then Updates: a newer OpenRig is available, an app update of 15 MB that runs when OpenRig restarts, with an Install button" caption="A newer version is out: an app update, a few megabytes." />

When a check has found an update ready to install, or an update waits for a restart, a dot shows
on the **⋮** button and next to **Updates** in the menu. Nothing is checked in the background: the
dot comes after a check.

**Close** (or a hold on the encoder) closes the dialog; a download or an install carries on.
Right after a release, the update files take a few hours to build: the dialog says so and asks to
check again later.

:::note[Before OpenRig 0.14.0]
Updates were a card of **Settings**.
:::

## App or system

OpenRig picks the smallest update that works:

- **App update**: when the new release runs on the same system, only the app is replaced. It is
  a few megabytes. Once it is installed, **Restart OpenRig** restarts the app in a few seconds.
- **System update**: when the release needs a new system (kernel, drivers, libraries), the whole
  system is written next to the running one, while you keep playing. This takes a few minutes;
  keep the pedalboard on. Then **Restart now** restarts the pedalboard on the new system.

Both keep your presets, setlists, models, Wi-Fi networks, TONE3000 link and `pedalboard.txt`.

## If an update fails

Updates cannot leave the pedalboard unusable:

- The system has two slots, A and B. A system update is written to the slot that is not
  running, then tried **once**. If the pedalboard's UI does not run for 30 seconds on it, the
  board restarts on the previous system.
- An app update is tried the same way: if the new app crashes or hangs in its first 30 seconds,
  the previous app runs again.
- A power cut during the install or the first start leaves the previous version in place.

Updates are signed: the pedalboard installs only bundles signed with the OpenRig release key.

## Updating by hand

The same update files are on every release, and can be installed over [SSH](../../help/ssh/):

```bash
scp -O openrig-os-<version>-rpi5.raucb root@192.168.1.42:/data/update.raucb
ssh root@192.168.1.42
pedalboard-update install /data/update.raucb   # written to the slot not running
pedalboard-update reboot                       # start it, once
pedalboard-update status                       # slots, versions, last update
rm /data/update.raucb
```

Use `pedalboard-update install-app` with the `-app.raucb` file for an app update.
